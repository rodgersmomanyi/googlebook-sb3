## Patch sets (`scripts/apply_patches.py --set`)

| Set | Patches | Use |
|---|---|---|
| `base` | 0001 0002 | Reproduces the 2026-10-24 ICD `f7e9154f...` bit-identically (NV-01). |
| `8a` (default) | 0001 0002 0004 0005 0006 | Shipped payload ICD and `libgb_nvk.so`. |
| `8b` | 8a + 0003 | AHB (`VK_ANDROID_external_memory_android_hardware_buffer`), compile and API checks only. |

* **0001** rejects foreign gralloc modifiers instead of a Rust panic (abort).
* **0002** builds without libelf and stops advertising `VK_NVX_binary_import`.
* **0004** forces LINEAR for buffers shared with a foreign gralloc. It adds SW_WRITE_RARELY to the swapchain gralloc
  usage and CPU_WRITE_RARELY to the AHB usage. Detection: renderD128 is not NVK's node. Override:
  `debug.mesa.nvk.anb.linear`.
* **0005** sets up the LINEAR to tiled render shadow for ANB/AHB images too.
* **0006** makes `vkQueueSignalReleaseImageANDROID` return a sync_fd instead of `QueueWaitIdle` + -1. Fallback, or
  forced with `debug.mesa.nvk.anb.waitidle=1`: the old path.
* **0003** adds AHB import/export: MR !33700 rebased in Churro's structure, minus their double init and double free.

`run_build.sh <name> <set> [suffix]` and `run_queue.sh` (builder only) wrap these with logs in `logs/` and outputs in
`results/<name>/`. A clean build takes about 10 minutes on an idle builder.

## nvk_probe test modes (`-t`, comma list; `all` = every mode; exit 0 pass / 1 fail / 2 ICD error / 3 NO_DEVICE)

`offscreen`, `anb-swapchain`, `anb-linear`, and the Phase 8 gates:

* **`ahb-i915-readback` (gate G0).** Allocates an AHB with CPU_WRITE_RARELY|CPU_READ_RARELY|GPU_COLOR_OUTPUT|
  GPU_SAMPLED_IMAGE through minigbm/i915 and imports it into NVK (VkNativeBufferANDROID). It renders a per-pixel-unique
  pattern and releases with a sync_fd, then reads the buffer back bit-exactly twice: once with
  `AHardwareBuffer_lock` and once by sampling it on ANV (`/vendor/lib64/hw/vulkan.intel.so`, AHB import, compute
  `texelFetch`). CPU_READ_RARELY is added to the plan's usage because the NDK requires a CPU read usage for read locks.
* **`a17-swapchain-model`.** Runs Android 17 libvulkan's sequence: GPDIFP2 with the AHB handle type, then
  GrallocUsage4/3/2/1, then an allocation with SurfaceFlinger's consumer usage. It creates an ANB image with
  `VkSwapchainImageCreateInfoANDROID`, then calls `vkAcquireImageANDROID` and renders. It releases with a wait
  semaphore, waits for the sync_fd and checks the pixels on ANV.

`-T <s>` is a per-test watchdog (default 60 s). `-A <icd>` selects the ANV used for read-back.

## Self-test invocations (INTERFACES v1.2 25.3; the probe side of decision D4)

gb_power starts `gb_gfx_selftest` (root) on the first healthy bind per identity; `gb_dgpu_report.sh selftest`
(nouveau-policy) then runs, after setting `foreign`, exactly:

```
timeout 150 nvk_probe -t ahb-i915-readback -T 60
timeout 150 nvk_probe -t a17-swapchain-model -T 60
```

with the default ICD (`$NVK_ICD`, then `/vendor/lib64/hw/vulkan.nouveau.so` -> the payload ICD) and the default ANV leg
(`/vendor/lib64/hw/vulkan.intel.so`). Exit codes and what the script makes of them (25.3 step 7): 0 pass; 1 `fail
<mode>` (also a driver hang caught by the probe's own `-T 60` alarm, printed as `TIMED OUT`); 124/137 from `timeout`
`fail <mode> timeout`; 2 `error icd`; 3 `error nodevice`. The `ahb-i915-readback` verdict requires the ANV leg (an
unavailable ANV is a FAIL), so the pair cannot pass without a bit-exact read-back on Intel.

v1.2 changes to make the probe safe as an unattended root gate (`src/nvk_probe.c`, "Supervision"):

* A stop signal (TERM/INT/HUP) to the probe SIGKILLs the running test child, reaps it (at most 5 s) and then ends the
  probe with that signal; the probe gets SIGTERM when its parent (`timeout`) dies; every test child has
  `PR_SET_PDEATHSIG(SIGKILL)`. Before, a TERM to the probe's pid alone (the script's trap) left the test child running
  as an orphan with the device open, and a killed `timeout` left both running - which is what nouveau-policy's
  `st_interrupted()` trap does (`kill $PROBE_PID`, the `timeout` pid) (`selftest_invocation.sh` S5-v11, S6-v11,
  S9-v11; with the v1.2 probe S5, S6, S9 leave nothing, S9 within 400 ms).
* The parent also enforces `-T`: a test child still alive 5 s after its own alarm is SIGKILLed (`TIMED OUT`).
* A test asked for by name that the build lacks (host build), or a run in which no test ran, is never a PASS (exit 1).
* An explicit `-d`/`-A` path that does not exist is `error icd` (exit 2) instead of a silent fallback to `$NVK_ICD` or
  the defaults (the old code only stopped after a failed `dlopen`, not after a failed `access`).

Evidence (2026-10-25, `logs/wave1b/`): `selftest_invocation.sh` in the 276.R4 chroot with drm-shim TU117 (S1/S2 exact
invocations: exit 1 after 60/61 s, `fail <mode>`, nothing left; S3 `timeout 5` 124; S4 `-s KILL` 137; S5 supervisor
SIGKILLed, S6 TERM to the probe, S9 gb_dgpu_report.sh's own trap path: nothing left; S7 3; S8 2), `probe_host_checks.sh` PASS 11/11, `run_checks.sh`
NV-02/03/06 PASS with the new binary (`nvk_probe` imports 58, 0 unresolved; NEEDED unchanged).
